## 1. 웹 자료 수집 도구
| 상황 | 쓰는 것 |
|---|---|
| 대화 중 조사·웹페이지 확인·데이터 추출 | **ego-browser(ego lite) 기본**. 시작 전 `ego-browser skill` 안내를 따른다 |
| ego-browser가 실패하거나 안 맞을 때 | WebFetch·curl·Playwright·Chrome 확장으로 대체 — **이유를 한 줄** 알린다 |
| 예약 실행 수집기 코드에서 브라우저가 필요할 때 | `solo_common.ego_browser`의 `browser_page()` (비동기는 `async_browser_page()`). ego lite가 없으면 모듈이 자동으로 대체 |
| 공식 Open API(키 발급형)·RSS | 브라우저 없이 HTTP 호출 가능 |

- **Playwright 직접 호출 금지는 수집기 한정.** 화면 점검·영상 확인용 Playwright(예: `content-engine/video`)는 허용.
- 브라우저 없이 잘 되던 수집이 차단·빈 응답을 내면 `browser_page()`로 바꾼다.

## 2. 예절 수집 (2026-11-02 전체 적용)
- 집 회선 IP 하나로 나가므로 차단을 피하는 것이 우선.
- 사이트마다 **무작위 대기** + **방문 순서 섞기**, 429·403(차단 신호)이 오면 그 실행을 멈춘다.
- 시작 시각은 흔들지 않는다 (작업 순서가 깨짐).
- robots.txt의 Crawl-delay보다 짧게 요청하지 않는다. 과도한 병렬 다운로드 금지.
- 공용 도구: `solo_common.polite` (PoliteSession·pace·run_shuffled).

## 3. robots·약관 원칙 (사장님 결정 5, 2026-11-11)
- 새 출처는 **robots.txt와 이용약관을 먼저 확인**한다.
- **약관이 자동 수집을 금지하면 쓰지 않는다.** 예외는 아래 표에 있는 것만 — **약관상 금지인 사이트는 표에 없으면 수집 불가.** (약관이 허용하거나 정해진 바 없는 사이트는 이 표와 무관)
- 영리 이용 금지 조항이 있으면 사장님 결정을 받고, 사이트·블로그 노출은 스위치(기본 꺼짐)로 막는다.
- robots.txt가 막은 경로는 쓰지 않는다 (예: 네이버 스포츠, FotMob `/api/`).
- 공공누리 자료는 유형 조건을 지킨다 (예: KNCAP 제3유형 — 출처 표기·원값 유지).

- **네이버 카페는 직접 수집하지 않는다** — `cafe.naver.com` robots.txt가 모든 봇을 막고 AI·RAG 용도를 명시 금지. 카페 글은 네이버 공식 검색 API(NAVER API HUB '카페글 검색 결과 조회')의 제목·요약만 쓴다(2026-11-14 사장님 결정, cadam `collect/trends/naver_cafe_questions.py`). (엔카는 위 예외 표 — 2026-11-13 전엔 "엔카 API 금지"로 적혀 있었으나 실제 수집기가 그 주소를 쓰고 있었다.)
- 약관·금지 조항이 없어 예외 표 대상이 아닌 곳: 무공해차 통합누리집(ev.or.kr, 한국환경공단) 충전요금 — 2026-11-13 사장님이 사이트·블로그 노출 허용. 출처 "무공해차 통합누리집(한국환경공단)" 표기, 월 1회 화면 1번 읽기 유지.

## 5. 수집기 운영 (요약 — 상세는 COLLECTOR_CONVENTION)
| 항목 | 규칙 |
|---|---|
| 저장 위치 | 숫자·표 → 데이터 창고(로컬 PostgreSQL) / 맥락 → second-brain `raw/` / 사이트가 읽는 값 → Supabase. Supabase에도 쓰면 **창고 먼저** |
| 등록 | 정기 수집기는 모두 launchd plist로 등록하고 스케줄을 적는다. 수동 전용은 문서에 "수동". 미등록 정기 수집기 금지 |
| 중복 | seen-log 또는 DB upsert(자연키) — 다시 돌려도 중복 저장 없음 |
| 건수 | 실행마다 저장 건수를 로그에 — "성공+0건"과 "성공+N건"을 구분 |
| 실패 | 단계별 try/except, 비정상 종료는 exit code ≠ 0, 셸은 `set -e` + `trap … ERR`. 일시 오류는 재시도(점점 늦게) |
| 알림 | ① 실패 알림 ② "성공인데 0건이 이어짐" 알림 — 공용 헬퍼(notify·section7)만. 0건이 정상인 작업은 ①만 |
| 비밀 | 토큰 하드코딩 금지, `.env`에서 읽기 |
| 호출 한도 | 한도 있는 API는 하루 예산·커서로 나눠 돈다 |
| 로그 | 그 작업 코드가 있는 프로젝트의 `logs/` 아래. 홈 루트·`~/logs`·`~/Downloads`·도구 임시폴더 금지 |
| `/tmp` | **잠금 파일만 허용** (예: `/tmp/football_blog.lock`). 로그·결과물 금지 |
