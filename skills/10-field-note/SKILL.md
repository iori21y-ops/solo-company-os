# 현장 메모 → 위키 (field-note)

## 목적
사장님은 장기렌트 실무를 위키보다 정확히 안다(2026-11-15: 위키는 '대부분 돌려받는다'·'드물다', 실제는 '다 돌려받는다'·'안 돌려받는다'). 생각날 때마다 남긴 말을 **원문 그대로 보관**하고, 맞는 위키 페이지에 **맥락(현장 설명)** 으로 붙이고, 규칙으로 단정할 것은 **확정 사실**로 올린다. 글쓰기(심층글·종합뉴스)는 현장 설명을 AI가 쓴 위키 문장보다 먼저 받고, 확정 사실은 조건 없이 단정해 쓰며, 초안 검사(`wiki_factcheck.py`)는 확정 사실과만 대조한다.

## 언제 쓰나 (트리거)
- 사장님이 "현장메모: …", "이거 위키에 남겨", "업무 지식인데 기억해 둬"라고 할 때 (어느 폴더의 세션이든)
- `raw/`에 이름이 `현장메모`로 시작하는 노트가 있을 때 (폰 옵시디언에서 쓴 것 — 밤 인제스트가 처리, 세션에서 "현장메모 정리해줘"면 지금 처리)
- "확정 사실 확인해줘" — `wiki/discussions/확정사실-대기.md` 처리

## 순서
1. **원문 저장 (말 바꾸지 않음)**: `python3 ~/second-brain/scripts/field_note.py save "<사장님 말 그대로>"` → `raw/현장메모-YYYYMMDD-HHMMSS.md`. 옵시디언 노트면 이미 raw/에 있으니 건너뜀.
2. **페이지 찾기**: `python3 ~/second-brain/scripts/field_note.py suggest <파일>` → 뜻이 가까운 페이지(점수 0.65 이상이면 거의 그 주제). 메모가 여러 주제면 문장마다 나눠 각 페이지로. 맞는 페이지가 없으면(최고 0.6 미만) `wiki/discussions/현장-설명-미분류.md`에 두고 log에 "새 질문 페이지 후보".
3. **현장 설명 붙이기**: 그 페이지의 `## 현장 설명 (사장님)` 칸(없으면 `## 확정 사실` 바로 아래, 그것도 없으면 `## 작동 원리` 위에 만든다)에 `- YYYY-MM-DD · <정리한 문장>`.
   - 사장님 말의 뜻만 옮긴다. 맞춤법·문장 다듬기만, **새 사실·조건·추측을 보태지 않는다**. 사장님이 쓴 숫자(수수료 금액 등)는 그대로 둔다.
   - 같은 내용이 이미 있으면 새 줄을 늘리지 말고 날짜만 더한다.
4. **같은 페이지의 어긋나는 문장 고치기**: 그 페이지(와 `확정 사실` 칸)에 현장 메모와 반대되는 문장이 있으면 고치고, 어떤 문장을 왜 고쳤는지 사장님께 한 줄 보고. 고치기 전 백업(`~/projects/_data/shared/backups/manual/wiki-field-note-<날짜>/`).
5. **확정 사실 후보**: 규칙처럼 단정할 문장("~는 항상/모두 ~다", "~는 돌려받지 않는다")은
   - 세션 중이면 그 자리에서 사장님께 "확정 사실로 올릴까요?" 한 번 묻고, 예면 `## 확정 사실 (사장님 확인)`에 `- 문장 (YYYY-MM-DD 확인)`.
   - 밤 인제스트(사장님 없음)면 `wiki/discussions/확정사실-대기.md`에 `- [ ] 문장 → [[concepts/페이지]] (YYYY-MM-DD 현장메모)`로만 적는다. 확정 사실 칸에 직접 넣지 않는다.
6. **마무리**: 원문 파일을 `raw/ingested/`로 옮기고, `wiki/log.md`에 `## [날짜] update | 현장 메모 반영` + 영향받은 페이지. 색인은 매일 05:50에 자동(급하면 `python3 ~/second-brain/scripts/wiki_embed.py`).

## "확정 사실 확인해줘"
`wiki/discussions/확정사실-대기.md`의 `- [ ]` 줄을 번호를 붙여 보여 주고, 사장님이 맞다/틀리다/고침을 말하면: 맞음 → 해당 페이지 `## 확정 사실 (사장님 확인)`에 `(YYYY-MM-DD 확인)`으로 넣고 대기 목록에서 지움. 고침 → 고친 문장으로 넣음. 틀림 → 지우고 그 페이지의 같은 문장도 고침.

## 하지 않는 것
- 현장 설명·확정 사실을 AI가 지어내거나 "보강"하지 않는다. 자동 작업(weekly_summary·post_findings·context_producer·인제스트)은 확정 사실 칸을 고치지 않는다(CLAUDE.md §3.4).
- 사장님 메모에 개인정보(고객 이름·연락처·차량번호)가 있으면 빼고 옮기고, 원문 파일에서도 그 부분을 지워 달라고 말씀드린다.
