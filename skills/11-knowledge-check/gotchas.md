# 함정 (Gotchas)

- 고친 AI 문장은 다음 `next`에서 새 문장으로 다시 잡힌다. 고침을 확정 사실 칸에 넣어 두면 비슷한 문장은 자동으로 '이미 확정'으로 빠진다 — 그래서 고침 ④(확정 사실에 넣기)를 빼먹지 말 것.
- `ok`는 `asked`로 기록한 짧은 문장을 확정 사실에 넣는다. `asked`를 빼먹으면 위키 원문(긴 문장)이 들어간다.
- 페이지 이름에 한글 자모가 분리(NFD)된 파일이 있을 수 있다 — 스크립트가 NFC로 맞춘다. 손으로 경로를 칠 때 주의.
- 사장님 답에 고객 이름·연락처·차량번호가 있으면 빼고 옮긴다(field-note와 같음).
- 사장님 답이 애매하거나 맥락이 어색하면(범위가 '전부'인지 '일부'인지, 개인/법인 구분, 누구 얘기인지) **고쳐 넣기 전에 다시 묻는다**(2026-11-15 사장님 지시). '만'·'대부분'·'개인'처럼 사장님이 안 한 한정어를 붙이지 말 것 — 첫 반영 때 '무심사 광고는 대부분 소형사'라고 덧붙였다가 되돌림.
- 사장님 답의 기준은 대부분 **여전사(캐피탈·카드사)와 대형 렌터카사**다. 중소형 렌터카사는 회사마다 제각각이라 단정하지 않는다. 문장을 보여 줄 때 누구 얘기인지 섞이면 대상을 밝혀 묻는다(2026-11-15).
- '중고차 장기렌트(빌려 타기)'와 '중고차 대출·할부(사기)'를 섞지 말 것 — 문장에 '중고차 심사'처럼 쓰지 말고 '중고차 장기렌트 심사'로.
- `field_note.py save`는 파일 이름이 초 단위라 **같은 초에 여러 번 부르면 앞 것이 덮어써진다**(2026-11-15 실제 발생). 원문을 여러 개 저장할 땐 사이에 `sleep 1.2`를 넣는다.
- **약관 원문·추출 칸은 Supabase가 아니라 맥 로컬 데이터 창고 DB**(`warehouse` 스키마, 2026-11-12 이전)에 있다. supabase-query로 찾으면 칸이 없다고 나온다. 읽기: `sys.path`에 `~/projects/_shared` 넣고 `from solo_common import warehouse as W; W.connect()` → `warehouse.terms_documents.raw_text`·`warehouse.terms_key_conditions`(SELECT만).
- `ok`는 확정 사실 칸에 **자동으로** 줄을 넣는다. 고침을 손으로 반영할 때 맞음 문장을 다시 손으로 넣지 말 것(2026-11-15 두 페이지에서 중복 발생 → 지움).
- **트림·옵션·차종 사양 문장은 사장님께 묻지 않는다** (2026-11-15 사장님 지시). 사장님은 시장 경험치를 답하는 사람이고, 트림·옵션은 제조사 데이터(가격표·CADAM 트림 데이터)로 판단한다. `next`에 그런 문장이 나오면 `skip`하고, 필요하면 데이터와 대조해 Claude가 고친다.
